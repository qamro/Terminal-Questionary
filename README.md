# Interactive CLI Questionnaire with Questionary

**A simple Python command-line application demonstrating how to build interactive terminal prompts using the questionary library. The program collects the user's name, lets them select a web framework and multiple tutorial topics, and asks for confirmation before displaying the final selection.**

---

# Technologies:

**Python, Questionary**

---

# Concepts:

**Interactive CLI, text input, single selection, multiple selection, confirmation prompts, string joining.**
